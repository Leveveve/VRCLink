麦克风电平

设备Host API16 kHz电平（peak / rms dBFS）
尚未加载，点「刷新设备列表」

适配器配置里的「麦克风设备」是下拉列表（插件启动时自动检测本机可用 16 kHz 的输入设备，首项 = 跟随 Windows 系统默认）。 换了麦克风后点「刷新麦克风列表」会把新列表写入配置——但下拉要重启 bot（或禁用/启用插件）后才会更新；本页设备列表与「测电平」即时可用。
经验参考：peak > -50 dBFS 才算「能听见人声」；正常说话时 -30 ~ -10 dBFS 较理想； peak ≈ 0 且提示触顶说明增益过大（削波）。「测电平」会录音 2 秒（只测电平，不识别），期间请自然说话或保持安静。
